# Final-Project---Bank-Marketing-Campaign
Prediksi keberhasilan telemarketing deposito bank menggunakan Machine Learning (HistGradientBoosting). Analisis EDA statistik, F2-score optimization, dan evaluasi berbasis nilai ekonomi (Euro) menghasilkan lift 2,49x vs random targeting, berpotensi menambah ~2,75 juta Euro nilai penempatan per kampanye.
